# HelloApp

HelloApp is a simple Java application project.

The project starts with printing **Hello World**, then gradually improves to display a user name, read names from command-line arguments and standard input.

The application will later manage names in a collection with options to add or remove names. The code will be refactored into methods and classes, and persistence will be added so names remain between runs.

Finally, the application will display names in a banner format.

## Features

* Print Hello World
* Display user name
* Read command line input
* Manage names in a collection
* Add and remove names
* Save names for later use
* Display names in banner format
